# 英文实验文档

12 篇文档均来自 Apache Hadoop 3.4.3 官方技术文档，采用 Apache License 2.0。
`sources.json` 保存各文件标题、原始网址、UTC 下载时间、字节数、原始分词数和 SHA-256。

预处理只提取网页主体 `bodyColumn` 内可见文本，去除导航、脚本、样式及多余空白，保存为 UTF-8。
主体内目录、命令示例和配置示例保留。因此本实验的统计对象是技术文档主体文本，而非纯自然语言段落。

索引分词规则：只识别连续的 ASCII 英文字母 `[A-Za-z]+`，转小写后过滤 `stopwords.txt`。
数字、标点、连字符均作为分隔符；不进行词干提取或词形合并。

```bash
python3 scripts/fetch_documents.py
```

重新下载可能因官网修订而产生不同内容；复现实验应优先使用本仓库中保存的数据。
